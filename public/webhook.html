Dokumentasi Signature & Payload
Format Payload
Semua payload dibungkus { "event": "...", "data": {...}, "sentAt": "..." }. Header X-AustinPay-Event juga berisi nama event yang sama. Server tujuan wajib membalas HTTP 200 dalam 10 detik, kalau gagal/timeout AustinPay otomatis retry hingga 3 kali.
Verifikasi Signature (Node.js)
const crypto = require('crypto'); function isValid(rawBody, signature, secret) { const expected = crypto .createHmac('sha256', secret) .update(rawBody) .digest('hex'); return crypto.timingSafeEqual( Buffer.from(signature, 'hex'), Buffer.from(expected, 'hex') ); } // signature = req.headers['x-austinpay-signature']
Setiap webhook punya secret sendiri — pastikan verifikasi pakai secret milik webhook yang bersangkutan.
