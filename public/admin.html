QRIS (Mutasiku)
Satu-satunya metode deposit: QRIS statis + cek mutasi via Mutasiku. Nonaktifkan di bawah ini kalau deposit perlu dimatikan sementara.

QRIS statis merchant (contoh: QRIS ShopeePay Merchant). Nominal tiap deposit DISISIPKAN otomatis ke string ini (jadi QR "dinamis" per transaksi) — tidak generate lewat API manapun. Ganti di sini kalau QRIS fisik/akun penerima berubah, tidak perlu ubah kode.

Dari dashboard Mutasiku > Settings > API Keys. Dipakai cek mutasi (uang masuk) buat matching status bayar QRIS.

Akun e-wallet/bank yang menerima pembayaran QRIS statis di atas (mis. ShopeePay Merchant). Akun ini dihubungkan LANGSUNG di dashboard Mutasiku (mutasiku.co.id) — tidak ada alur link/OTP di sini.

Daftarkan webhook di dashboard Mutasiku > Settings > Webhooks, arahkan ke https://domain-kamu/api/webhook/mutasiku, subscribe event mutations.created, lalu isi secret yang sama di sini.

Berlaku server-side untuk SEMUA sumber polling (web app maupun integrasi API pihak ketiga) — kalau ada request check status yang datang lebih cepat dari ini, dijawab pakai status tersimpan tanpa hit ulang ke Mutasiku, supaya tidak kena rate limit di sisi provider.

Setelah QR lewat masa berlaku di atas, deposit belum langsung ditandai "Expired" permanen — dikasih tenggang waktu ini dulu buat jaga-jaga kalau mutasi Mutasiku telat settle (biasa 1-3 menit dari waktu bayar). Selama tenggang ini, sistem tetap coba cocokkan mutasi yang masuk telat.

Berlaku untuk semua nominal deposit, dihitung dari nominal dasar. Kode unik tidak lagi diacak: otomatis +1, +2, dst. hanya kalau nominal total sama dengan deposit pending lain.

Withdraw Instant (OkeConnect H2H)
Withdraw Instant (topup e-wallet user) memakai OkeConnect H2H.
OkeConnect (H2H)
Semua produk OkeConnect di sini "Bebas Nominal" (Open Denom) — user isi nominal sendiri (Rp100 - Rp10.000.000), bukan pilih dari daftar nominal tetap.

Ditambahkan di atas (nominal + biaya produk OkeConnect). Default Rp300/transaksi.

Rate Limit & Proteksi Abuse API
Disimpan terpisah dari tombol di atas dan langsung berlaku (tanpa restart server). Batas khusus per user (mis. payment gateway) bisa diatur dari menu Riwayat Request.
