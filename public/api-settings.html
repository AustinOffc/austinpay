Public API

Atur kredensial API kamu di halaman ini (API key, API secret, dan whitelist IP), lalu baca dokumentasi endpoint untuk mulai integrasi. Pengaturan webhook ada di halaman Webhook.

Buka Dokumentasi API
API Key
Setiap request Public API wajib menyertakan API key (lewat query ?apikey=, header X-API-Key, atau Authorization: Bearer) dan dikirim dari IP yang sudah masuk whitelist.

API Secret (HMAC Signature)
API secret dipakai untuk menandatangani (HMAC-SHA256) tiap request lewat header X-Timestamp & X-Signature. Kalau secret sudah dibuat, HMAC signature jadi wajib. Secret hanya ditampilkan sekali saat dibuat/diganti — catat baik-baik.
