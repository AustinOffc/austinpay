API Key
Setiap request Public API wajib menyertakan API key (lewat query ?apikey=, header X-API-Key, atau Authorization: Bearer) dan dikirim dari IP yang sudah masuk whitelist. Request yang tidak memenuhi keduanya akan ditolak. Endpoint deposit & withdraw bisa dipanggil dari path yang sama baik lewat dashboard (sesi login) maupun API key — server membedakan otomatis dari kredensial yang kamu kirim.

API Secret (HMAC Signature)
API secret dipakai untuk menandatangani (HMAC-SHA256) tiap request Public API lewat header X-Timestamp & X-Signature — tambahan di luar API key, bukan pengganti. Kalau kamu sudah generate secret, HMAC signature jadi wajib untuk key ini; request tanpa signature valid akan ditolak. Secret hanya ditampilkan sekali saat dibuat/diganti — catat baik-baik.
