Mode Live menampilkan request sungguhan dari server AustinPay (nama client ditampilkan di atas paket; IP, nominal, dan ID transaksi tidak pernah dikirim). Durasi total dan jumlah query database adalah hasil ukur asli; animasi sengaja diperlambat supaya terbaca. Tombol Kirim request mengirim ping sungguhan ke server dan kamu akan melihatnya melintas.
